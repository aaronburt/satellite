Set up iCUE RGB

RGB readings need Corsair's iCUE SDK. Download and install it yourself from Corsair's official SDK page. Satellite does not download or install it.

  1. Download the Windows SDK archive from Corsair's SDK downloads and review Corsair's licence terms.
  2. Extract iCUESDK.x64_2019.dll from the archive's redist/x64 folder. Create %APPDATA%\satellite\sdk if needed and copy the DLL there, or put it beside satellite.exe.
  3. Keep iCUE running. Allow Satellite in iCUE's SDK settings when asked.
